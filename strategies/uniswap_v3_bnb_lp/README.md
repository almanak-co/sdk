# BNB Uniswap V3 LP

> Fixed-range Uniswap V3 LP on BNB Chain USDT/WBNB: swap half the USDT, mint, increase, partially decrease, collect, hold, then exit to USDT.

USDT/WBNB reference using an explicitly configured fee-500 pool; providers and the
fork fixture are operator inputs.
`almanak support --connector uniswap_v3 --chain eip155:56` states the
declaration; fork proofs use simulated funds.
