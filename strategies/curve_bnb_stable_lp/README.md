# BNB Curve stable LP

> Curve StableSwap NG LP on BNB Chain crvUSD/USDT: two funds swap, add, increase, partially remove, hold, then exit proportionally or to USDT.

Two named fund accounts execute the shared Curve helper. The author configuration selects its exact pool, ordered assets and explicit funding. `almanak support --connector curve --chain eip155:56` states the declaration; fork proofs use simulated funds. Backtest costs are explicitly excluded; native fork reports retain payer costs. External historical pool states remain fixed.
