# PancakeSwap V3 BNB LP

> Fixed-range PancakeSwap V3 LP on BNB Chain USDC/WBNB: swap half the WBNB, mint, increase, partially decrease, collect, hold, then exit to WBNB.

The explicit configuration starts with 0.1 wrapped BNB, uses the configured
USDC/WBNB 2500-fee pool and a fixed tick range, and returns to WBNB on exit.
Token names are display metadata; CAIP references establish financial identity.

Broader NFT manager grants can affect compatible owned or approved NFTs; gateway
operations require the retained strategy-owned NFT.
`almanak support --connector pancakeswap_v3 --chain eip155:56` states the
declaration; fork proofs use simulated funds.
